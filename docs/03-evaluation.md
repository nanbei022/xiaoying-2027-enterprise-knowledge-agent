## 验收方法

完成提案须满足：回答非空、至少一条引用、没有尚未解决的必要信息；每条引用的文档须由本轮 read_document 成功读取，段落 ID 须对应读取结果，非空引句须为该段原文的连续子串。冲突记录中的文档也须已读取。校验失败会以结构化错误返回模型，模型可在剩余额度内修正；达到上限仍未通过时返回 limit_reached。

此校验仅检查证据身份和原文一致性，不会自动判定引句是否在语义上支持回答。对全部实际输出另做了人工核对：检查是否满足场景要求、是否触犯禁止行为，以及关键结论是否与引用内容相符。一次运行的结果不能当作稳定准确率。

## 当前限制

1. 原文子串校验不等于语义支持校验。新问题或复杂多条款回答仍需人工检查结论与引文的对应关系。
2. 示例资料是合成的小规模知识库；20 个场景是一次性验收样本，不代表真实企业资料上的泛化能力或统计准确率。
3. 受控故障和首轮空结果只检验模型观察后的动作调整，不证明真实工具的稳定性或检索质量。
